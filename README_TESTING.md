# テストドキュメント

## テストスイート

このプロジェクトには、半角全角の組み合わせでバグが出やすいケースを検出するための包括的なテストスイートが含まれています。

### テストファイル

1. **test_runner.sh** - 基本的なテストランナー
   - 表示幅の計算検証
   - 境界ケース
   - 半角全角混在
   - 半角カナ
   - フィールド長オーバー
   - 特殊文字

2. **test_comprehensive.sh** - 包括的なテストスイート
   - 15種類の詳細なテストケース
   - C言語版とシェルスクリプト版の一致性検証
   - 自動判定と結果レポート

### テストの実行

```bash
# 包括的テストの実行
./test_comprehensive.sh

# 基本テストの実行
./test_runner.sh
```

### テストカバレッジ

以下のケースをカバーしています：

#### 1. 文字幅の境界値
- **奇数幅に全角文字**: 幅5のフィールドに幅2の全角文字を配置
- **1文字幅フィールド**: 幅1に全角文字（幅2）は入らない
- **全角文字が幅を超える**: 全角文字が指定幅を超える場合の切り詰め

#### 2. フィールド境界の処理
- **境界で全角文字が分断**: フィールド境界で全角文字が切れない
- **空白のみのフィールド**: トリミング後に空文字列になる

#### 3. 文字種の混在
- **半角カナ**: 半角カナ（幅1）と全角文字（幅2）の混在
- **複雑な混在**: 半角、全角、半角カナ、記号の混在
- **特殊Unicode文字**: 絵文字や記号などの特殊文字

#### 4. 空白文字の扱い
- **全角空白**: 全角空白（U+3000）はトリミングしない
- **半角空白**: 半角空白とタブはトリミングする
- **空白のみのフィールド**: 空白のみのフィールドの処理

#### 5. CSVエスケープ
- **カンマを含むフィールド**: CSVエスケープが正しく動作
- **引用符を含むフィールド**: ダブルクォートの二重化

#### 6. 極端なケース
- **長い行**: フィールド幅を大きく超える行
- **タブ文字**: タブ文字が含まれる行
- **制御文字**: 制御文字の処理

## バグが出やすいケースの説明

### ケース1: 奇数幅に全角文字

```
入力: あいうえおかきくけこ
幅指定: 5,5
期待出力: あい,えお
```

**説明**: 幅5のフィールドに全角文字（幅2）を配置すると、「あい」（幅4）しか入らない。「う」（幅2）を追加すると幅6になるため含まれない。

### ケース2: 全角空白の扱い

```
入力: 前　全角空白　後
幅指定: 10,10,10
期待出力: 前　全角空,白　後,
```

**説明**: トリミングオプション（`-t`）は半角空白とタブのみを削除し、全角空白（U+3000）は削除しない。

### ケース3: フィールド境界で全角文字が切れる

```
入力: あいうえおABCDE
幅指定: 10,10
期待出力: あいうえお,ABCDE
```

**説明**: 「あいうえお」（幅10）がちょうどフィールド幅に収まる。全角文字が途中で切れることはない。

### ケース4: 半角カナの幅

```
入力: ｱｲｳｴｵｶｷｸｹｺABCDE
幅指定: 10,10,10
期待出力: ｱｲｳｴｵｶｷｸｹｺ,ABCDE,
```

**説明**: 半角カナは幅1として扱われる。「ｱｲｳｴｵｶｷｸｹｺ」（10文字、幅10）がちょうど収まる。

### ケース5: 1文字幅フィールド

```
入力: あいうえお
幅指定: 1,1,1,1,1
期待出力: ,,,,
```

**説明**: 幅1のフィールドには全角文字（幅2）が入らないため、すべて空フィールドになる。

## テスト結果の読み方

```
[テスト] 奇数幅(5)に全角文字
  説明: 幅5のフィールドに全角文字（幅2）を配置。'あい'（幅4）しか入らない
  幅指定: 5,5
  ✓ PASS: C言語版とシェルスクリプト版が一致
  出力例:
    あい,えお
    ABCDE,FGHIJ
```

- **✓ PASS**: テスト成功
- **✗ FAIL**: テスト失敗（詳細な差分が表示される）

## テスト入力ファイル

### test_cases.txt
基本的なテストケースの集合。コメント行を含むため、実際のデータファイルのテストにも使用できる。

### test_edge_cases.txt
エッジケースの集合。幅5,7,8の不規則なフィールド幅でテスト。

## 新しいテストの追加

新しいテストケースを追加するには、`test_comprehensive.sh`に以下の形式でテストを追加します：

```bash
# テストN: 説明
cat > testN.txt << 'EOF'
テストデータ
EOF
test_case "テスト名" "testN.txt" "幅指定" \
    "詳細な説明"
```

## トラブルシューティング

### テストが失敗する場合

1. **ロケール設定を確認**: `LANG=C.UTF-8`が設定されているか
2. **改行コード**: 入力ファイルがLF（`\n`）を使用しているか
3. **文字エンコーディング**: 入力ファイルがUTF-8か

### 手動でのテスト

```bash
# C言語版
LANG=C.UTF-8 ./fixed2csv -w 10,20,10 -d , -t input.txt output_c.csv

# シェルスクリプト版
./fixed2csv.sh -w 10,20,10 -d , -t input.txt output_sh.csv

# 比較
diff -u output_c.csv output_sh.csv
```

## CI/CDへの統合

テストスクリプトは終了コードを返すため、CI/CDパイプラインに統合できます：

```bash
# 成功時: 終了コード 0
# 失敗時: 終了コード 1
./test_comprehensive.sh
```
