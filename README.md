# UTF-8 固定長ファイル変換ツール

UTF-8エンコーディングの固定長ファイルを可変長ファイル（CSV/TSV）に変換するツールです。

**重要**: このツールは**表示幅ベース**（半角文字=1、全角文字=2）で固定長を扱います。

## 概要

このリポジトリには、固定長ファイルを可変長に変換する2つのバージョンが含まれています：

1. **fixed2csv.c** - C言語版（高速、wcwidth()使用）
2. **fixed2csv.sh** - シェルスクリプト版（Python3使用）

## 表示幅について

このツールは、**表示幅**（ディスプレイ上での文字の幅）に基づいて固定長を扱います：

- **半角文字** (アルファベット、数字、記号など): 幅 = 1
- **全角文字** (日本語、中国語、韓国語など): 幅 = 2

例:
- `"ABC"` → 表示幅 = 3
- `"あいう"` → 表示幅 = 6
- `"A1あ"` → 表示幅 = 4 (1 + 1 + 2)

## 機能

- UTF-8マルチバイト文字（日本語など）に対応
- 表示幅ベースでフィールドを切り出し（半角=1、全角=2）
- 任意の区切り文字を指定可能（カンマ、タブ、パイプなど）
- フィールドの前後の空白を削除（オプション）
- CSVエスケープ処理（クォート、改行を含むフィールドの処理）

## C言語版の使い方

### コンパイル

```bash
gcc -o fixed2csv fixed2csv.c
```

または

```bash
make
```

### 使用例

```bash
# 基本的な使い方（フィールド幅: 10, 20, 15）
./fixed2csv -w 10,20,15 -d , input.txt output.csv

# タブ区切り（TSV）で出力
./fixed2csv -w 16,40,10 -d $'\t' input.txt output.tsv

# 空白をトリミング
./fixed2csv -w 10,20,15 -d , -t input.txt output.csv

# パイプ区切り
./fixed2csv -w 10,20,15 -d '|' input.txt output.txt
```

### オプション

- `-w widths`: 各フィールドの**表示幅**をカンマ区切りで指定（必須）
  - 例: `-w 10,20,15` は3つのフィールド（表示幅10、20、15）
  - **注意**: バイト数や文字数ではなく、表示幅です
- `-d delimiter`: 出力の区切り文字（デフォルト: `,`）
  - タブ: `-d $'\t'`
  - パイプ: `-d '|'`
- `-t`: フィールドの前後の空白を削除
- `-h`: ヘルプを表示

### 必要な環境

- C言語コンパイラ（gcc等）
- ロケールがUTF-8に設定されていること
- wcwidth()関数をサポートするシステム

## シェルスクリプト版の使い方

### 実行権限の付与

```bash
chmod +x fixed2csv.sh
```

### 使用例

```bash
# 基本的な使い方
./fixed2csv.sh -w 10,20,15 -d , input.txt output.csv

# タブ区切り（TSV）で出力
./fixed2csv.sh -w 16,40,10 -d tab input.txt output.tsv

# 空白をトリミング
./fixed2csv.sh -w 10,20,15 -d , -t input.txt output.csv
```

### オプション

C言語版とほぼ同じですが、タブ文字の指定は以下のいずれかを使用：
- `-d tab`
- `-d $'\t'`

### 必要な環境

- Bash
- **Python 3**（unicodedataモジュールを使用）

## 入力ファイルの例

固定長ファイルの例（表示幅ベース）：

```
山田太郎  営業部              2023-01-15
鈴木花子  開発部              2023-02-20
佐藤次郎  総務部              2023-03-10
```

各行のフィールド構成（表示幅ベース）：
- フィールド1: 10（`山田太郎  ` = 4全角 + 2半角 = 8+2 = 10）
- フィールド2: 20（`営業部              ` = 3全角 + 14半角 = 6+14 = 20）
- フィールド3: 10（`2023-01-15` = 10半角 = 10）

上記のファイルを `-w 10,20,10` で変換すると：

```csv
山田太郎,営業部,2023-01-15
鈴木花子,開発部,2023-02-20
佐藤次郎,総務部,2023-03-10
```

トリミングオプション（`-t`）を使用すると、余分な空白が削除されます。

## サンプルファイル

テスト用のサンプルファイルを作成するには：

```bash
# サンプルファイル作成（表示幅ベース）
cat > sample_input.txt << 'EOF'
山田太郎  営業部              2023-01-15
鈴木花子  開発部              2023-02-20
佐藤次郎  総務部              2023-03-10
田中美咲  企画部              2023-04-05
伊藤健一  人事部              2023-05-12
EOF

# C言語版で変換
gcc -o fixed2csv fixed2csv.c
./fixed2csv -w 10,20,10 -d , -t sample_input.txt sample_output.csv

# または、シェルスクリプト版で変換
chmod +x fixed2csv.sh
./fixed2csv.sh -w 10,20,10 -d , -t sample_input.txt sample_output.csv

# 結果を確認
cat sample_output.csv
```

## 表示幅の計算方法

文字の表示幅は、East Asian Width（東アジアの文字幅）に基づいて決定されます：

| 文字種別 | 表示幅 | 例 |
|---------|-------|---|
| 半角英数字 | 1 | A, 1, @ |
| 半角カナ | 1 | ｱ, ｲ, ｳ |
| 全角ひらがな | 2 | あ, い, う |
| 全角カタカナ | 2 | ア, イ, ウ |
| 全角漢字 | 2 | 山, 田, 太 |
| 全角記号 | 2 | 、, 。, 「 |

## 注意事項

### C言語版

- UTF-8エンコーディングのファイルのみサポート
- ロケールが正しく設定されている必要があります（`LC_ALL=ja_JP.UTF-8`等）
- wcwidth()関数を使用するため、環境によって動作が異なる場合があります
- 最大行長: 65536バイト
- 最大フィールド数: 256

### シェルスクリプト版

- Python3が必要
- unicodedata.east_asian_width()を使用
- C言語版と同等の精度で表示幅を計算

## どちらを使うべきか？

| 用途 | 推奨バージョン |
|------|---------------|
| 高速処理、大容量ファイル | C言語版 |
| Python環境がある | シェルスクリプト版（簡単） |
| コンパイル環境がない | シェルスクリプト版 |
| 組み込みシステム | C言語版 |
| クロスプラットフォーム | シェルスクリプト版 |

## よくある質問

### Q: 文字数ではなく表示幅で指定する理由は？

A: 日本語などの全角文字を含む固定長ファイルは、一般的に「見た目の幅」で整列されています。画面やプリンタで表示した時に縦に揃って見えるようにするため、全角文字は半角文字の2倍の幅を持ちます。

### Q: バイト数で指定することはできますか？

A: このツールは表示幅専用です。バイト数ベースの固定長ファイルには対応していません。

### Q: フィールドの途中で全角文字が切れる場合は？

A: 次の文字を追加すると指定幅を超える場合、その文字は含まれません。フィールドは指定幅より短くなる可能性があります。

## トラブルシューティング

### ロケールエラー（C言語版）

```bash
# ロケールを設定
export LC_ALL=ja_JP.UTF-8
export LANG=ja_JP.UTF-8

# または実行時に指定
LC_ALL=ja_JP.UTF-8 ./fixed2csv -w 10,20,10 -d , input.txt output.csv
```

### Python3が見つからない（シェルスクリプト版）

Python3をインストールしてください：
```bash
# Ubuntu/Debian
sudo apt-get install python3

# CentOS/RHEL
sudo yum install python3

# macOS
brew install python3
```
