# UTF-8 固定長ファイル変換ツール

UTF-8エンコーディングの固定長ファイルを可変長ファイル（CSV/TSV）に変換するツールです。

## 概要

このリポジトリには、固定長ファイルを可変長に変換する2つのバージョンが含まれています：

1. **fixed2csv.c** - C言語版（高速、UTF-8完全対応）
2. **fixed2csv.sh** - シェルスクリプト版（AWK使用、軽量）

## 機能

- UTF-8マルチバイト文字（日本語など）に対応
- 任意の区切り文字を指定可能（カンマ、タブ、パイプなど）
- フィールドの前後の空白を削除（オプション）
- CSVエスケープ処理（クォート、改行を含むフィールドの処理）

## C言語版の使い方

### コンパイル

```bash
gcc -o fixed2csv fixed2csv.c
```

### 使用例

```bash
# 基本的な使い方（フィールド幅: 10, 20, 15文字）
./fixed2csv -w 10,20,15 -d , input.txt output.csv

# タブ区切り（TSV）で出力
./fixed2csv -w 8,12,20 -d $'\t' input.txt output.tsv

# 空白をトリミング
./fixed2csv -w 10,20,15 -d , -t input.txt output.csv

# パイプ区切り
./fixed2csv -w 5,10,15,20 -d '|' input.txt output.txt
```

### オプション

- `-w widths`: 各フィールドの文字幅をカンマ区切りで指定（必須）
  - 例: `-w 10,20,15` は3つのフィールド（10文字、20文字、15文字）
- `-d delimiter`: 出力の区切り文字（デフォルト: `,`）
  - タブ: `-d $'\t'`
  - パイプ: `-d '|'`
- `-t`: フィールドの前後の空白を削除
- `-h`: ヘルプを表示

## シェルスクリプト版の使い方

### 実行権限の付与

```bash
chmod +x fixed2csv.sh
```

### 使用例

```bash
# 基本的な使い方
./fixed2csv.sh -w 10,20,15 -d , input.txt output.csv

# タブ区切り（TSV）で出力
./fixed2csv.sh -w 8,12,20 -d tab input.txt output.tsv

# 空白をトリミング
./fixed2csv.sh -w 10,20,15 -d , -t input.txt output.csv
```

### オプション

C言語版とほぼ同じですが、タブ文字の指定は以下のいずれかを使用：
- `-d tab`
- `-d $'\t'`

## 入力ファイルの例

固定長ファイルの例（各フィールドが決まった文字数）：

```
山田太郎  営業部              2023-01-15
鈴木花子  開発部              2023-02-20
佐藤次郎  総務部              2023-03-10
```

上記のファイルを `-w 10,20,10` で変換すると：

```csv
山田太郎,営業部,2023-01-15
鈴木花子,開発部,2023-02-20
佐藤次郎,総務部,2023-03-10
```

トリミングオプション（`-t`）を使用すると、余分な空白が削除されます。

## サンプルファイル

テスト用のサンプルファイルを作成するには：

```bash
# サンプルファイル作成
cat > sample_input.txt << 'EOF'
山田太郎  営業部              2023-01-15
鈴木花子  開発部              2023-02-20
佐藤次郎  総務部              2023-03-10
田中美咲  企画部              2023-04-05
EOF

# C言語版で変換
gcc -o fixed2csv fixed2csv.c
./fixed2csv -w 10,20,10 -d , -t sample_input.txt sample_output.csv

# または、シェルスクリプト版で変換
chmod +x fixed2csv.sh
./fixed2csv.sh -w 10,20,10 -d , -t sample_input.txt sample_output.csv

# 結果を確認
cat sample_output.csv
```

## 注意事項

### C言語版

- UTF-8エンコーディングのファイルのみサポート
- ロケールが正しく設定されている必要があります
- 最大行長: 65536バイト
- 最大フィールド数: 256

### シェルスクリプト版

- AWK（gawk推奨）が必要
- UTF-8の処理は簡易的なため、複雑なマルチバイト文字の処理で問題が発生する可能性があります
- 高精度なUTF-8処理が必要な場合は、C言語版を推奨

## どちらを使うべきか？

| 用途 | 推奨バージョン |
|------|---------------|
| 高速処理、大容量ファイル | C言語版 |
| 複雑なUTF-8文字（絵文字など） | C言語版 |
| 簡単な日本語テキスト | どちらでも可 |
| コンパイル環境がない | シェルスクリプト版 |
| 軽量・手軽に使いたい | シェルスクリプト版 |
